# API Restful - Sistema de Registro Acadêmico

 API Restful de um sistema de registro academico para fixação de conceitos relacionados ao desenvolvimento de sistemas Web, aplicando conceitos relacionados ao Padrão de Projeto (Design Pattern): **Repository**.

---

### ⚙️ Pré-requisitos

Ter o Python instalado na sua máquina:

```bash
# 🐧 Linux (Debian/Ubuntu)
sudo apt install python3 python3-pip

# 🍎 macOS (via Homebrew)
brew install python

# 🪟 Windows
winget install Python.Python.3
```
---

### 🔧 Instalação

**1. Clonar o repositório**
```bash
git clone https://github.com/DouglasCruzz10/api_restful_registro-academico.git
```

**2. Criação de Ambiente Virtual**
```bash
Python -m Venv venv
\venv\Scripts\activate
```

**3. Instalação de Requisitos**
```bash
Python -r requirements.txt
```
**4. Criação das Variáveis de Ambiente**
```bash
1. Criar arquivo "credentials.env"
2. Inserir as informações a seguir:

DB_USER = "Inserir usuário do banco de dados"
DB_PASSWORD = "Inserir Senha do banco de dados"
DB_HOST = "Inserir host do servidor"
DB_NAME = "Inserir o nome do Banco de dados"

```
**5. Executar o sistema**
```bash
Python app.py
```
